## What it does

<!-- BEGIN AUTO-GENERATED: overview -->
Read-only backlog planning across Azure DevOps, GitHub, and Jira: discover candidate work from requests, documents, or search; retrieve and enrich assigned work into an implementation handoff; triage existing items; plan a sprint or iteration; and resume an interrupted planning workflow. Resolves the backing tracker at runtime and never creates, updates, transitions, or comments on an item. Use for backlog discovery, triage, sprint planning, my-work retrieval, task-planning handoff, and workflow
resumption.
