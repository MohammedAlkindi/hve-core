# Sample Project

A small fixture repository used by the baseline-equivalence suite.

Both the baseline and customized runs receive an identical copy of this
directory, so any difference in how an agent edits it is attributable to the
customization layer rather than to differing starting conditions.

## Usage

```bash
npm install
npm start
```

## Structure

* `src/index.js` — entry point
* `scripts/` — helper scripts
* `package.json` — dependencies and npm scripts
